# A17 · Configuración de GitHub Pages
**Responsable:** Azucena

## Pasos
1. En el repositorio: **Settings → Pages**.
2. **Source:** Deploy from a branch.
3. **Branch:** `main`, carpeta `/ (root)` → **Save**.
4. A los 1–2 minutos el sitio queda publicado en:
   `https://li21001.github.io/Proyecto-Pagina-Web-Ministerio-de-Sordos/`
5. El panel queda en `…/panel/login.html`.

## Después de activarlo
- Agregar el dominio `li21001.github.io` en Firebase → Authentication → Settings → **Authorized domains** (sin esto, el inicio de sesión falla en el sitio publicado).
- Cada commit a `main` actualiza el sitio automáticamente.
- Probar en celular y computadora que cargan todas las secciones.

## Al cierre del proyecto (A42)
El repositorio se transfiere o se replica en una cuenta de GitHub del ministerio (creada con su correo) para que la publicación no dependa de una cuenta personal.
